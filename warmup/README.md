# Shelka Aim — разминка аима

Отдельный мод: только спавн тренировочного бота. Никаких аура/нейро/читов — чистая мишень.

## Установка

1. Fabric Loader 0.19.5+, Minecraft 1.21.11, Fabric API.
2. Положить `shelka-aim-1.0.0.jar` в папку `mods`.

## Команды

| Команда | Что делает |
| --- | --- |
| `.bot spawn [ник]` | поставить бота в 3 блоках перед собой (по умолчанию `Target`) |
| `.bot remove` | убрать ближайшего бота |
| `.bot clear` | убрать всех ботов |
| `.bot move [on\|off]` | включить/выключить движение (по умолчанию включено) |
| `.bot speed <0.05–5.0>` | скорость движения, `1.0` — как в оригинале |
| `.bot help` | список команд |

Скорость и режим движения сохраняются в `config/shelka-aim.properties`.

## Что умеет бот

- Живёт только на клиенте: сервер его не видит, атаки никуда не уходят.
- Нетрит + тотем: при попадании — hurt-анимация, партиклы, звук, отлёт; «смерть» = поп тотема.
- Движение: стрейфы в стороны, смена дистанции 2.2–4.0 блока, редкие прыжки; всегда смотрит на тебя.
